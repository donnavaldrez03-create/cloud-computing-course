# Google Cloud Platform (GCP) Research

## 1. Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers cloud services for computing, storage, databases, networking, artificial intelligence, data analytics, and application development.

## 2. Global Infrastructure

Google Cloud operates a global infrastructure consisting of Regions and Zones. Regions are geographic locations where Google Cloud resources can be deployed, while Zones are isolated locations within a Region that help improve availability and reliability.

## 3. Cloud Management Console

The Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources and services. Users can manage projects, virtual machines, storage, databases, networking, and other cloud services through the console.

## 4. Key Services

### Google Compute Engine

Google Compute Engine provides virtual machines that allow organizations to run applications and workloads in the cloud.

### Google Cloud Storage

Google Cloud Storage provides scalable object storage for files, images, videos, backups, and other types of data.

### Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed Kubernetes service used to deploy, manage, and scale containerized applications.

### BigQuery

BigQuery is a fully managed data warehouse that allows organizations to analyze large datasets using SQL.

## 5. Three Advantages

1. GCP provides scalable cloud infrastructure that can support applications and large workloads.
2. GCP offers a wide range of services for computing, storage, databases, networking, analytics, and artificial intelligence.
3. GCP provides global infrastructure that helps organizations deploy applications closer to their users.

## 6. Typical Enterprise Use Cases

GCP can be used for web and mobile application hosting, data analytics, artificial intelligence and machine learning, database workloads, containerized applications, data storage, and disaster recovery.
