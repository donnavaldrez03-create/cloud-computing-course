AWS RESEARCH
1. Brief Overview

Amazon Web Services (AWS) is a public cloud computing platform that provides a wide range of infrastructure and technology services. It allows organizations to use computing, storage, databases, networking, security, and other resources through the cloud instead of maintaining all physical infrastructure themselves.

2. Global Infrastructure

AWS operates a global infrastructure organized into geographic Regions and Availability Zones. AWS Regions are separate geographic areas, while Availability Zones are isolated locations within a Region. This infrastructure helps organizations deploy applications with better availability, scalability, and fault tolerance.

3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Through the console, users can create and configure cloud resources, monitor services, manage security settings, and control their AWS environment.

4. Four Core Services

Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) provides virtual servers that organizations can use to run applications and workloads in the cloud.

Amazon S3

Amazon Simple Storage Service (Amazon S3) is an object storage service used to store and retrieve files, documents, images, backups, and other types of data.

Amazon RDS

Amazon Relational Database Service (Amazon RDS) is a managed relational database service that simplifies the process of setting up, operating, and scaling relational databases.

AWS IAM

AWS Identity and Access Management (IAM) helps organizations control who can access AWS resources and what actions users and applications are allowed to perform.

5. Three Advantages
Wide range of services – AWS provides many cloud services that can support different technical and business requirements.
Global infrastructure – Its worldwide Regions and Availability Zones support applications that need availability and global deployment.
Scalability – AWS resources can be increased or decreased according to application requirements and workloads.
6. Typical Enterprise Use Cases

AWS can be used by enterprises for web and mobile applications, data storage and backup, database hosting, business applications, disaster recovery, analytics, and large-scale digital services. Its broad service portfolio allows organizations to build and operate different types of workloads on the same cloud platform.
