# Cloud Computing Reflection

Cloud computing has become an important part of my daily life, even if I do not always notice it. I regularly use several cloud-based applications that make communication, learning, and file storage easier.

One cloud service I frequently use is **Google Drive**. It is classified as **Software as a Service (SaaS)** because I can store, organize, and access my files through a web browser without installing or managing any servers. It uses a **Public Cloud** deployment model because it is available to anyone with a Google account.

Another cloud service I use is **Facebook Messenger**. It is also a **SaaS** application because it provides messaging, voice calls, and video calls over the internet. Messenger runs on a **Public Cloud**, allowing millions of users worldwide to communicate using the same cloud infrastructure.

I also use **Canva** for creating presentations, posters, and school projects. Canva is another example of **SaaS** since it offers online design tools through a web browser. It is hosted on a **Public Cloud**, making it accessible from different devices with an internet connection.

Version control is essential in cloud computing because many developers often work on the same project at the same time. Without version control, important files could be overwritten or lost. Git and GitHub help developers keep track of every change made to the project, making it easy to review previous versions or restore files when mistakes occur. GitHub also supports teamwork by allowing developers to work on different branches, review code through pull requests, and merge updates safely. These features improve collaboration, reduce errors, and ensure that cloud projects are organized and reliable.
